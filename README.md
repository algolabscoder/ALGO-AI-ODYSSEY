# ALGO AI ODYSSEY

Fresh GitHub Pages package for Algo Labs.

## Upload these files to the repository ROOT

- index.html
- style.css
- game.js
- README.md

Do NOT create css/ or js/ folders for this package.

The HTML references:
- ./style.css
- ./game.js

## GitHub Pages
1. Replace the existing files with these files.
2. Commit to main.
3. Settings → Pages → Deploy from branch → main → /(root).
4. Wait for deployment.
5. Open the Pages URL and press Ctrl+F5.

## Local test
Run `python -m http.server 8080` in this folder and open http://localhost:8080.
