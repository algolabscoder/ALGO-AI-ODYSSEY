# AI FRONTIER — Algo Labs

A playable frontend MVP for an educational GenAI & Agentic AI game.

## Run

Open `index.html` directly in a browser, or use VS Code Live Server.

Alternative:

```bash
python -m http.server 8080
```

Then open http://localhost:8080

## Included

- Premium sci-fi / cyberpunk visual UI
- Responsive mobile layout
- Algo Labs onboarding
- Avatar selection
- XP, levels and credits
- Interactive world map
- Python / GenAI / RAG / Agent missions
- Answer feedback and progression
- Final boss battle
- Leaderboard
- No backend required for this MVP
